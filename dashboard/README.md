# Dashboard y reportes

El dashboard principal está integrado en `src/app.js`.

Indicadores calculados:

- Proyectos activos.
- Casos de prueba.
- Bugs abiertos.
- Cobertura.
- Passed.
- Failed.
- Pending.
- Defectos por severidad.

La sección de reportes permite imprimir/guardar la vista en PDF mediante la función de impresión del navegador.
