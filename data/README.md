# Datos

Los datos del prototipo son **simulados** y están definidos en `src/mock-api.js`.

No se utilizan datos bancarios, credenciales reales ni información personal de clientes. Al ejecutar la aplicación, la información se persiste en `localStorage` del navegador.

`qa_manager_seed.json` resume el conjunto inicial utilizado para la demostración.
