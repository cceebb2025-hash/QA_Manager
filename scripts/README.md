# Scripts

Las operaciones de datos se implementan en `src/mock-api.js`.

No se requieren scripts de instalación ni dependencias externas. La capa `QAApi` funciona como una API simulada con operaciones de creación, consulta, actualización y eliminación.

Operaciones principales:

- `createProject()`, `updateProject()`, `deleteProject()`
- `createRequirement()`, `updateRequirement()`, `deleteRequirement()`
- `createCase()`, `updateCase()`, `deleteCase()`
- `executeCase()`
- `createBug()`, `updateBug()`, `deleteBug()`
- `updateSettings()`
