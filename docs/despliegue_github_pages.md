# Despliegue en GitHub Pages

1. Se crea un repositorio llamado, `QA-Manager`.
2. Se sube todo el contenido del proyecto.
3. se verica que `index.html` esté en la raíz.
4. Ir a **Settings → Pages**.
5. Se selecciona **Deploy from a branch**.
6. Se selecciona `main` y `/root`.
7. Guardar.
8. Se espera el despliegue.
9. y se abre la URL proporcionada por GitHub Pages.

## Validación posterior

Comprobando que:

- La página carga correctamente.
- El menú lateral funciona.
- Se pueden crear registros.
- Se pueden editar y eliminar registros.
- Los KPI cambian al modificar los datos.
- Al recargar, los datos permanecen.
- El botón de impresión permite guardar el reporte en PDF.
